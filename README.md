# 重勘：柳林雨夜旧案

一款以卷宗调查为核心的本格推理网页游戏。

**开始游戏：<https://xiaoxiong-game.github.io/liulin/>**

> 十八年前，柳林江堤连环杀人案的罪犯被执行死刑。十八年后，你的室友许禾在参与旧卷宗数字化项目时失踪了。你唯一能找到的，是她留在宿舍的电脑。

- 建议用电脑玩；没有声音；电脑上的每个软件都会在新的标签页打开。
- 三种结局，进度自动保存在本机浏览器。
- 卡关了可以来小红书找作者。不建议翻源码，答案和结局都写在里面，翻到就没意思了。

故事纯属虚构 · 创作者/开发者：小熊饼干。游戏中的地名、人物、机构和案件均为虚构，与现实无关，如有雷同，切勿当真。
